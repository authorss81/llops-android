## Feature 1 — Note stats bar (word count, reading time, characters)

`TextToolsAnalyzer.analyze(text)` already returns `wordCount`,
`characterCount`, `paragraphCount`, `readingTimeSeconds`
(`TextToolsAnalyzer.kt:26-42`, `NoteflowPlugin.kt:181` `readingTimeSeconds`). The
editor/preview does NOT surface them. Add a small, unobtrusive stats footer/line
in `MarkdownPreviewScreen` (visible in both editor and reader mode, hidden on
reduced-motion/no need) showing "1,234 words · ~6 min read · 5,678 chars",
computed debounced off the current document WITHOUT a full re-tokenize on every
keystroke (reuse the cached document model; recompute only when the text length
or block count changes materially). Pure-JVM policy formatting
(`services/NoteStatsFormatPolicy.kt` with locale-safe number formatting) + test.

Definition of done Feature 1: stats line renders, updates debounced, formatting
tested; `assembleDebug` green.

## Feature 2 — Outline quick-jump in reader/preview

`OutlineGeneratorCore` (`plugins/outline/OutlineGeneratorCore.kt`) already
produces a markdown heading outline and `MarkdownPreviewScreen` has an outline
dialog (phase-157-era `OutlineGeneratorDialog`, `showOutline` state). Add a
**quick-jump** affordance in reader/focus mode: an anchored outline rail
(collapsible) that scrolls the preview to the tapped heading. Reuse the
existing outline engine output; delegate scrolling to the preview's
scrollstate; NO re-parsing (map already-parsed heading blocks to scroll
positions via a precomputed heading index). Respect reduce-motion (instant
scroll) and keep the rail collapsed by default.

Definition of done Feature 2: outline rail in reader mode with heading
quick-jump; a pure-JVM `services/HeadingScrollIndex.kt` (heading text → offset)
with tests; `assembleDebug` green.

## Feature 3 — Wiki-link autocomplete & insertion in the editor

In the hybrid editor, typing `[[` currently has no completion. Add a small
autocomplete popup over `[[` that suggests existing note titles from the cached
vault (bounded by `WikiLinkParser` limits / cached corpus; no new DB reads) and
inserts `[[title|display]]`. Respect: fails cleanly when the vault is locked (no
suggestions + no crash); suggestions bounded (cap, dedupe, stable order); the
slash-menu (`SlashCommandMenuPopup`, `MarkdownPreviewScreen.kt:773-778`) gains a
"Insert wiki-link" entry that opens the same suggestion flow.

Definition of done Feature 3: `[[` triggers suggestions and insertion works in
the editor; closed/safe when locked; pure-JVM policy for suggestion ranking
(`services/WikiSuggestionPolicy.kt`) + tests; `assembleDebug` green.
