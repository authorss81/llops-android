**Evidence:** `AnnotationCanvas.kt:3144` + `3259` cached path `drawStrokeWithSymmetry(stroke, offsetY-pageTopY, m, centreX, centreY-pageTopY)` uses **local** centre `764` against **world** `p.y` (e.g. page1 `pageTopY=1592`, `p.y=1692` → `m=-164 → -1756` off-screen; correct world `2*2356-1692=3020 → 1428` local). Preview path `3152,3277` uses world centre correctly → divergence. Page 0 `pageTopY=0` hides bug. `symmetryCenterFor:506-518` OK, eraser `921-922` OK world.

**Repro:** Note `divideIntoPages=true` continuous + `symmetryMode=VERTICAL`, draw page0 OK, scroll page2 draw → mirrored copy missing/off-screen. Activates with `LayerBitmapLruCache`.

**Fix:** Keep centre world: `drawStrokeWithSymmetry(stroke, offsetY-pageTopY, m, symmetryCenterX, symmetryCenterY)` + mirror using world `p.y`; or convert points to local before `mirrorPoint`. Add `SymmetryHelperTest` page1 mirror.

**Feasibility:** Trivial 2-line fix, no architecture change. **Recommended YES.**
